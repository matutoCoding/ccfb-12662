# 导光板网点设计与出光仿真系统（LGP Dot Studio）

面向中小尺寸背光模组（车载屏 / 工控屏导光板）的浏览器端网点设计与蒙特卡洛出光仿真工具。
**TypeScript + WebGL2 + Web Worker，纯前端、零服务端，所有数据存于本机浏览器 IndexedDB。**

## 解决的痛点

改一版网点就开一次模（数万元、两周周期）。本系统让光学工程师在浏览器里完成
「网点排布 → 出光仿真 → 均匀度评估 → 按误差自动反推修正」的完整闭环，把开模前的
方案验证成本降到分钟级。

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run test       # 物理引擎单元测试（15 项）
npm run preview    # 预览生产构建
```

## 物理模型（不是假动画）

每个网格单元的照度都来自真实的蒙特卡洛光线追踪，核心链路：

1. **光线注入**：按 LED 位置与朗伯角分布，在 TIR 导波锥内注入带能量权重的光线；
2. **Beer-Lambert 传播**：网点聚合成 2D 散射系数场 μ(x,y)（由真实网点覆盖率推导），
   沿光程指数衰减 `1-exp(-μ·ds)`，散射事件的能量完全来自网点几何，不凭空赋亮度；
3. **能量分配**：散射能量分为顶面有效出光、底面抽出经反射片按反射率回收、网点吸收，
   全部计入能量审计（实测守恒偏差 ~1e-11）；
4. **理想导光边界**：板内光全反射，能量只经网点抽取离开导光体；
5. **扩散片**：按雾度与扩散距离对出光照度做高斯展宽。

**可复现性**：每根光线用 `mulberry32(seed, rayIndex)` 独立随机流，同参数两次运行
照度数组逐位相等（有单元测试守护）。

**九点均匀度**：严格按行业常规 `min(九点照度) / mean(九点照度)` 计算。

## 关键工程决策

- **网点存储**：稠密网格单元 + 定长槽位 + 自由链表 O(1) 增删，支持百万级容量；
- **WebGL2 渲染**：instanced quad 单次 draw call，76 万网点实测交互 51–54 FPS；
- **仿真隔离**：全部计算在 Web Worker，主线程不卡顿；任务串行队列 + IndexedDB 持久化；
- **自动修正**：以 `目标均值/局部照度` 构造误差图，松弛 0.6 + 3×3 邻域平滑，
  乘性更新密度因子（限幅 [0.5,2]），实测一轮可把均匀度从 0.43 提升到 0.70（+27 个百分点）；
- **零重型运行时依赖**：UI/图表/报告全部手写，React 是唯一运行时依赖。

## 数据与隐私

方案、网点场、仿真任务全部保存在浏览器 IndexedDB（库名 `lgp-dot-studio`），
不发任何网络请求。方案包用 CompressionStream 做 gzip，可离线发给同事导入。
